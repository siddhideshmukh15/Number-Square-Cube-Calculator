# Number Square Cube Calculator

A simple **Number Square Cube Calculator** built using Python. This beginner-friendly project takes a number from the user and calculates its square and cube.

## Features

- Accepts a number from the user
- Calculates the square of a number
- Calculates the cube of a number
- Displays the results clearly
- Supports decimal numbers

## Technologies Used

- Python
- User Input
- Arithmetic Operators
- Exponentiation Operator (`**`)

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the program:

    python Number-Square-Cube-Calculator.py

## Concepts Learned

- Taking user input
- Converting input using `float()`
- Variables
- Arithmetic calculations
- Exponentiation
- Printing output

## Example

    Enter a number: 5

    Square: 25.0
    Cube: 125.0
